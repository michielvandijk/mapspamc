# Package index

## All functions

- [`aggregate_to_adm()`](https://michielvandijk.github.io/mapspamc/reference/aggregate_to_adm.md)
  : Aggregates gridded results of alternative model to the
  administrative unit level of the target model

- [`align_raster()`](https://michielvandijk.github.io/mapspamc/reference/align_raster.md)
  : Both clips a raster to polygon and aligns it to reference grid

- [`calc_cropland_coverage()`](https://michielvandijk.github.io/mapspamc/reference/calc_cropland_coverage.md)
  : Calculates the balance between cropland and physical crop area

- [`check_statistics()`](https://michielvandijk.github.io/mapspamc/reference/check_statistics.md)
  : Checks the consistency of the subnational statistics

- [`combine_inputs()`](https://michielvandijk.github.io/mapspamc/reference/combine_inputs.md)
  : Combines all inputs into one GAMS gdx file

- [`combine_results()`](https://michielvandijk.github.io/mapspamc/reference/combine_results.md)
  : Combines GAMS output into one R rds file

- [`create_adm_list()`](https://michielvandijk.github.io/mapspamc/reference/create_adm_list.md)
  : Creates a file with information on how administrative units are
  nested

- [`create_adm_map_pdf()`](https://michielvandijk.github.io/mapspamc/reference/create_adm_map_pdf.md)
  : Creates a pdf file with maps of administrative unit locations

- [`create_all_tif()`](https://michielvandijk.github.io/mapspamc/reference/create_all_tif.md)
  : Creates tif files for all crop distribution maps produced by the
  model

- [`create_folders()`](https://michielvandijk.github.io/mapspamc/reference/create_folders.md)
  :

  Creates `mapspamc` folder structure

- [`create_grid()`](https://michielvandijk.github.io/mapspamc/reference/create_grid.md)
  : Creates country grid

- [`create_model_template()`](https://michielvandijk.github.io/mapspamc/reference/create_model_template.md)
  :

  Creates `mapspamc` model template

- [`create_statistics_template()`](https://michielvandijk.github.io/mapspamc/reference/create_statistics_template.md)
  : Creates template for subnational crop statistics

- [`harmonize_inputs()`](https://michielvandijk.github.io/mapspamc/reference/harmonize_inputs.md)
  : Harmonizes crop statistics, cropland and irrigated area extent

- [`load_data()`](https://michielvandijk.github.io/mapspamc/reference/load_data.md)
  : Load model input data for further processing

- [`mapspamc_par()`](https://michielvandijk.github.io/mapspamc/reference/mapspamc_par.md)
  :

  Sets `mapspamc` parameters

- [`prepare_cropland()`](https://michielvandijk.github.io/mapspamc/reference/prepare_cropland.md)
  : Prepares synergy cropland extent

- [`prepare_irrigated_area()`](https://michielvandijk.github.io/mapspamc/reference/prepare_irrigated_area.md)
  : Prepares synergy irrigated area extent

- [`prepare_physical_area()`](https://michielvandijk.github.io/mapspamc/reference/prepare_physical_area.md)
  : Calculates physical crop area at the subnational level

- [`prepare_priors_and_scores()`](https://michielvandijk.github.io/mapspamc/reference/prepare_priors_and_scores.md)
  : Prepares grid cell priors and scores for all crops and production
  system combinations

- [`prepare_priors_and_scores2()`](https://michielvandijk.github.io/mapspamc/reference/prepare_priors_and_scores2.md)
  : Prepares grid cell priors and scores for all crops and production
  system combinations

- [`rasterize_adm_map()`](https://michielvandijk.github.io/mapspamc/reference/rasterize_adm_map.md)
  : Rasterizes the map with the location of the subnational
  administrative units

- [`reaggregate_statistics()`](https://michielvandijk.github.io/mapspamc/reference/reaggregate_statistics.md)
  : Reaggregates subnational statistics from the bottom up so they are
  consistent

- [`run_mapspamc()`](https://michielvandijk.github.io/mapspamc/reference/run_mapspamc.md)
  : Runs crop allocation algorithm at the set administrative unit level

- [`split_calc_cropland_coverage()`](https://michielvandijk.github.io/mapspamc/reference/split_calc_cropland_coverage.md)
  : Calculates cropland coverage in line with solve level

- [`view_results()`](https://michielvandijk.github.io/mapspamc/reference/view_results.md)
  : Compares crop distribution maps using a panel for each production
  system
